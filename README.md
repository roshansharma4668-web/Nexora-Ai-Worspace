# Nexora — AI-Powered Project Management & Team Collaboration Platform

Nexora is a full-stack MERN SaaS platform designed for modern teams to manage workspaces, projects, Kanban tasks, real-time notifications, team analytics, and AI-assisted project planning.

## Tech Stack
- **Frontend:** React 18, Vite 5, React Router 6, CSS Modules / Variables, @dnd-kit, Recharts, Socket.IO Client, Lucide React
- **Backend:** Node.js, Express.js, MongoDB Atlas, Mongoose 8, JWT (HTTP-Only Cookies), bcrypt, Zod, Socket.IO, Helmet

## Project Structure
- `/frontend` — React + Vite client application
- `/backend` — Node.js + Express REST & WebSocket server
